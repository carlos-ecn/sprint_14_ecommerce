# 🎯 Objetivo do Projeto

Este projeto tem como objetivo realizar uma análise técnica estruturada de dados de E-commerce, explorando dados transacionais para:

- Construir métricas de negócio relevantes
- Identificar padrões de comportamento de compra
- Avaliar concentração de receita
- Detectar sazonalidade e tendências
- Apoiar decisões estratégicas com base em dados

O foco principal está na aplicação prática de técnicas de Data Cleaning, Análise Exploratória (EDA) e construção de métricas de negócio, simulando um cenário real corporativo.

---

# 📈 Resultado

A análise permitiu:

- Identificação das categorias mais rentáveis
- Cálculo do ticket médio e análise de sua variação
- Avaliação da concentração de receita por cliente
- Identificação de padrões temporais (mensais e sazonais)
- Construção de métricas estratégicas para priorização comercial

O projeto demonstra capacidade de transformar dados brutos em informação estruturada e insights acionáveis, mantendo equilíbrio entre análise técnica e visão de negócio.

# 🔍 Descrição do Projeto

O projeto utiliza um dataset transacional de E-commerce contendo informações de pedidos, clientes, produtos e receita.

A análise foi conduzida com foco em:

- Receita total e evolução temporal
- Receita por categoria
- Receita por cliente
- Frequência de compra
- Ticket médio
- Concentração de faturamento

A granularidade é transacional (nível de pedido), permitindo análises agregadas por cliente, categoria e período.

---

# ⚙️ Metodologia

O projeto foi estruturado nas seguintes etapas:

## 1️⃣ Data Cleaning

- Tratamento de valores nulos
- Conversão de colunas para datetime
- Padronização de tipos
- Verificação de inconsistências

## 2️⃣ Feature Engineering

- Criação de variáveis temporais (mês, ano, dia da semana)
- Cálculo de receita por pedido
- Cálculo de ticket médio
- Agregações por cliente e categoria

## 3️⃣ Análise Exploratória (EDA)

- Análise de distribuição de receita
- Análise temporal
- Concentração de receita (Top clientes)
- Crescimento percentual
- Comparação entre categorias

## 4️⃣ Interpretação Estratégica

Cada análise foi acompanhada de interpretação voltada a possíveis aplicações reais, como:

- Campanhas direcionadas
- Gestão de estoque
- Segmentação de clientes
- Priorização comercial
